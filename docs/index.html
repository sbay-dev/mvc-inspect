🔍 mvc-inspect

أداة سطر أوامر قوية لتحليل وفحص مشاريع ASP.NET Core MVC

dotnet tool install --global MvcStructureInspector

المميزات

🌳

مخطط الهيكل

مخطط شجري تفصيلي لكل كلاس وحقن ومتحكم مع عدد الأعضاء النصي

⚖️

مقارنة المشاريع

تحديد الفجوات بين مشروعين: ملفات ناقصة، تواقيع مختلفة، مناظير Razor

📦

تحليل .csproj / .sln

مقارنة حزم NuGet والـ frameworks وإعدادات المشروع عبر الـ solution

🔒

حماية التقارير

كل تقرير بتوقيت فريد — لا كتابة فوق، سجل تاريخي كامل

📂

فتح تلقائي

خيار --open يفتح التقرير مباشرةً بعد الإنشاء

🛡️

آمن ومدقق

CodeQL + CycloneDX SBOM + اختبارات وحدة في كل نشر

الاستخدام

توليد مخطط الهيكل:

mvc-inspect --path ./MyProject --out report.txt

مقارنة مشروعين:

mvc-inspect --compare ./ProjectA --path ./ProjectB --out gap.txt

مقارنة مع تحليل .csproj / .sln:

mvc-inspect --compare ./ProjectA --path ./ProjectB --with-proj

فتح التقرير تلقائياً:

mvc-inspect --path ./MyProject --open

فتح تقرير موجود:

mvc-inspect open ./mvc-structure_20241205_143000.txt

Generate structure map:

mvc-inspect --path ./MyProject --out report.txt

Compare two projects:

mvc-inspect --compare ./ProjectA --path ./ProjectB --out gap.txt

Compare with .csproj / .sln analysis:

mvc-inspect --compare ./ProjectA --path ./ProjectB --with-proj

Auto-open report after generation:

mvc-inspect --path ./MyProject --open

Open an existing report:

mvc-inspect open ./mvc-structure_20241205_143000.txt

الخيارات (Flags)

الخيارالوصف
--path <dir>مسار المشروع المراد فحصه
--out <file>ملف الإخراج (اختياري، افتراضي: توقيت تلقائي)
--compare <dir>المشروع الأول في المقارنة
--with-projتضمين مقارنة .csproj و .sln
--openفتح التقرير تلقائياً بعد الإنشاء
--no-viewsاستبعاد مناظير Razor
--cs-onlyملفات C# فقط
--no-migrationsاستبعاد ملفات Migrations
open <file>فتح ملف تقرير محدد

الأمان والنزاهة

  • ✅ CodeQL يُشغّل تلقائياً على كل push وكل أسبوع
  • ✅ SBOM (CycloneDX) مرفق مع كل إصدار على NuGet
  • ✅ فحص التبعيات (Dependency Review) على كل Pull Request
  • ✅ 57 اختبار وحدة يُشغّل في كل CI قبل النشر
  • ✅ لا كتابة فوق الملفات — كل تقرير بتوقيت فريد محمي بـ SecurityGuard
  • ✅ الامتدادات المحمية (.exe, .dll, .wasm, .cs, ...) محظور الكتابة إليها

تقارير الأمان متاحة في تبويب Releases بالمستودع.
